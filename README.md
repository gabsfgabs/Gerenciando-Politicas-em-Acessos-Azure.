# Gerenciando Politicase em Acessos Azure.
Este repositório contém o resumo dos conteúdos referentes a aula de Gerenciamento de políticas em acesso Azure. 

O recurso Azure Policy tem como objetivo definir as políticas, iniciativa e atribuição ao ambiente dos aplicativos utilizados e geridos pela empresa.
Com a utilização desses recursos é possível ter maior controle da utilização dos aplicativos dentro da MV, com este gerenciamento, é possível utilizar
parâmetros genéricos nas atribuições dos usuários,que podem ser reutilizados em diversas situações, poupando tempo e diminuindo a probabilidade de erros 
durante a elaboração das atribuições.
